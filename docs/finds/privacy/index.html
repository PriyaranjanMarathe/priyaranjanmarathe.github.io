Saved Finds privacy policy

Updated September 20, 2026.

Saved Finds is Ranjan Marathe’s personal collection of material deliberately selected for his public website. It is not a service for monitoring WhatsApp groups.

Messages and selection

The connected Meta WhatsApp Business app receives messages sent directly to its number. The receiver checks the sender against a single configured owner number and ignores other senders. It does not read the owner’s WhatsApp groups or contact list.

Accepted message text, timestamps, message identifiers, reply references and attachment identifiers are held in a private Vercel Blob inbox. The owner selects an item by replying to that specific message with save, optionally followed by hashtags. An ordinary forward alone is not published. Unsupported message types are not published.

Publication

GitHub Actions reads the private inbox. Selected text is published on this website and in its public GitHub repository. Supported selected attachments are publicly accessible through links to the media store. Explicit hashtags are used when supplied; otherwise simple keyword rules suggest tags. No external AI service processes the content. Sender numbers, account IDs and original message IDs are excluded from the public records, but personal information contained in selected text or attachments is preserved.

Storage and retention

The importer normally runs hourly. During an inbox read, stored messages older than seven days are removed. If the importer is stopped or a service fails, cleanup is delayed until it resumes. Selected media is downloaded from Meta and published in a public Vercel Blob store; unselected attachments are not copied there. Older published attachments may also remain in the website repository. Meta, Vercel and GitHub also process operational data under their respective policies.

Published items remain until removed by the site owner. Removing an item from the page does not automatically remove previous Git history, search engine caches or copies made by other people. This personal service does not sell message data or use it for advertising.

Requests and deletion

For a question, correction or removal request, contact the site owner through the website repository’s issue tracker. Include the public item link; do not post private message contents, phone numbers or credentials. The owner can remove the current item and address repository history separately when appropriate.
